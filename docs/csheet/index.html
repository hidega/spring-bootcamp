Memory areas allocated by JVM
classloader is a component of JVM used to load class files.
class method area stores per-class structures such as the runtime constant pool, field and method data, and the code for methods.
heap is created a runtime and it contains the runtime data area in which objects are allocated.
stack stores local variables and partial results at runtime. Each thread creates a private JVM stack at the time of thread creation.
native method stack is reserved for all the native methods used in the application.
How do classloaders work
Classloader is a class that is used to load files in JVM. It loads files from their physical file locations e.g. Filesystem, Network location etc. There are three main types of classloaders in Java.
bootstrap classloader is the first classloader, it loads classes from rt.jar file.
extension classloader loads class files from jre/lib/ext location.
application classloader on CLASSPATH to find the location of class files.
What is a Thread
A thread in Java is a lightweight process that runs within another process or thread. It is an independent path of execution in an application. JVM gives each thread its own method-call stack. When we start JVM, Java starts one thread. This thread calls the main method of the class passed in argument to java call. Java 25 introduces virtual threads.
