aggregation composition
Aggregation and composition are association relations types.
Composition is a strong relationship. If the composite object is destroyed, then all its parts are destroyed.
Aggregation is a weaker relationship than composition.<br/>
E.g. a library has students. If a library is destroyed, students still exist.
So library and student are related by aggregation. A library has books. If a library is destroyed, the books are also destroyed.
Books of a library cannot exist without the library. So book and library are related by composition.
