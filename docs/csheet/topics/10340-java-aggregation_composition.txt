aggregation composition
In OOPS, aggregation and composition are the types of association relations. A composition is a strong 
relationship. If the composite object is destroyed, then all its parts are destroyed. In aggregation, 
the relationship is weaker than composition. E.g. a library has students. If a library is destroyed, 
students still exist. So library and student are related by aggregation. A library has books. If library 
is destroyed, the books are also destroyed. Books of a library cannot exist without the library. So 
book and library are related by composition.
