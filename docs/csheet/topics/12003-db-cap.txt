CAP
cap
The CAP theorem states that any distributed data store can provide only two of the following three guarantees:<br/> 
<i>Consistency</i>: Every read receives the most recent write or an error.<br/>
<i>Availability</i>: Every request  receives a (non-error) response, without the guarantee that it contains 
the most recent write.<br/>
<i>Partition tolerance</i>: The system continues to operate despite an arbitrary number of messages being 
dropped (or delayed) by the network between nodes.
