Classloader
classloader
Classloader is a class that is used to load files in JVM. It loads files from their
physical file locations e.g. filesystem, network location etc. There are three main types of classloaders.<br/>
<i>bootstrap classloader</i> is the first classloader, it loads classes from <span class="cs-pre">rt.jar</span> file.<br/>
<i>extension classloader</i> loads class files from <code>jre/lib/ext</code> location.<br/>
<i>application classloader</i> on CLASSPATH to find the location of class files.<br/>
